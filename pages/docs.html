What OffHorizon is

OffHorizon is Minecraft: Java Edition 26.3 rewritten in Rust. You install it with a small launcher, and it runs on the game files from your own copy of Minecraft. It is free, open source and unofficial.

In one minute

  • A new game program, not a mod. OffHorizon is written from scratch in Rust. It reads the same worlds, plays by the same rules and generates the same terrain as the Java game.
  • Checked against vanilla. 281 automated tests ("harnesses") feed the same inputs to OffHorizon and to the real game, then compare the results. Passing them is not proof that nothing else differs, and players still find differences. The status table shows what they covered when the project started.
  • Light and fast. It starts quickly, uses little memory and draws efficiently. See Performance for what is measured and what is not.
  • A few things vanilla doesn't have. Its own settings, added to vanilla's menus the way mods add theirs, graphics presets, distant terrain, controller support, optional extras such as dynamic lights, official mods such as zoom and a minimap, an invite code to play your world with friends, and a server you can run without Java.

What OffHorizon is not

  • Not Minecraft itself. OffHorizon contains no Minecraft code, assets or data, and it never downloads them. You need your own legally obtained copy of Minecraft: Java Edition 26.3. OffHorizon builds its game files from that copy, on your computer.
  • Not a place where Java mods run. Forge, NeoForge, Fabric and Quilt mod jars do not work in OffHorizon, and neither do Mixins. OffHorizon has its own mod system, and the launcher can port some Java mods' content. See Mods and data packs and Modpacks.
  • Not for other versions. OffHorizon plays Java Edition 26.3. Worlds from older versions (1.8 to 26.2) are upgraded the way vanilla upgrades them.
  • Not an official Minecraft product. It is not approved by or associated with Mojang or Microsoft.

Supported systems

  • Linux, x86-64. A graphics card with Vulkan drivers. Builds are made on Ubuntu 22.04, so use a distribution at least that recent.
  • macOS, Apple Silicon or Intel. Any M1 or newer, or an Intel Mac, on macOS 12 or later.
  • Windows, x64 or ARM64. Vulkan or DirectX 12. OffHorizon picks DirectX 12 by itself when Vulkan does not work, and first on ARM64 PCs (Snapdragon).

There is no build for 32-bit systems or ARM Linux. The server can be built from source on other systems.

Who makes it

OffHorizon is made by Ludovic Marie; reach him through lu4ovic.com (opens in a new tab). This site is developed by Anthony S of DezerX (opens in a new tab), who is responsible for it. OffHorizon contains no Minecraft code, assets or data, and this site offers no game files: you need your own legally obtained copy of Minecraft: Java Edition. Minecraft is a trademark of Mojang Synergies AB. OffHorizon's cosmetics are sold by Ludovic Marie through Paddle.com, the merchant of record.

Licences

OffHorizon's original work is under the MIT licence (opens in a new tab). The fonts are Geist, Geist Mono and Bricolage Grotesque, under the SIL Open Font License (opens in a new tab). Every asset on this site is listed in LEGAL.md.

Privacy

This site sets no cookies, has no analytics or trackers and loads nothing from third parties except GitHub. When you open a release, the server keeps a one-way hash of your IP address so that release counts each visitor once; the address itself is never stored. To show the latest releases, patch notes, links and contributors, your browser asks api.github.com and raw.githubusercontent.com for them, and avatars.githubusercontent.com for the contributors' pictures; GitHub's privacy statement (opens in a new tab) covers those requests. The launcher sends nothing at all: OffHorizon collects no telemetry (opens in a new tab).
