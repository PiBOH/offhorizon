What it is

Same inputs, identical outputs.

OffHorizon, sometimes called Minecraft Rust Edition, rebuilds Minecraft: Java Edition 0.2.2-nightly6.3 in Rust, one subsystem at a time, and holds every piece to the same inputs as the vanilla game until the outputs are identical.

Visit contributors(opens in a new tab)

  • Your own copy

    Install Java Edition with the official launcher and play 0.2.2-nightly6.3 once. OffHorizon builds its resources from those files on your machine, and never downloads or shares game files.

  • Native on three platforms

    Linux, macOS on Apple Silicon or Intel, and Windows on x64 or ARM. Worlds come from a Rust port of the vanilla generators, drawn with vanilla's block models, lighting, sky and fog.

  • Open source

    OffHorizon's code is MIT. It contains no Minecraft code, assets or data; those belong to Mojang and Microsoft under the Minecraft EULA.

Privacy

This site sets no cookies, has no analytics or trackers and loads nothing from third parties except GitHub. When you open a release, the server keeps a one-way hash of your IP address so that release counts each visitor once; the address itself is never stored. To show the latest releases, patch notes, links and contributors, your browser asks api.github.com and raw.githubusercontent.com for them, and avatars.githubusercontent.com for the contributors' pictures; GitHub's privacy statement (opens in a new tab) covers those requests.
