What to know before you play

OffHorizon is one portable file. It launches the Rust rewrite of Minecraft: Java Edition 26.3 and your own Java instances, with an offline account and no telemetry.

Install and first start

Download OffHorizon-Launcher-Windows-x64.exe (or the Linux file) from Releases and run it from wherever you keep it. There is no installer and no administrator prompt.

  • On its first start the launcher keeps a copy of itself in %APPDATA%\offhorizon\OffHorizon.exe, so the copy survives an emptied downloads folder.
  • It then asks once whether to add its shortcuts to the Start menu and the desktop. The same switch is in Settings → About → Shortcuts, and turning it off removes them again.
  • Nothing is registered as an installed program, so there is no entry in Settings → Apps.

Accounts

An empty account list gets an offline account automatically: a local name, with the OfflinePlayer:<name> UUID Java uses. Singleplayer and LAN work with it. Online servers still need a Microsoft account that owns the game.

What OffHorizon downloads

  • Mojang's public version files for Minecraft 26.3, and the libraries the game needs, when they are missing from your game folder.
  • Horizon game builds from horizon-rust/horizon, so the Rust game is always the latest build upstream publishes.
  • Launcher updates and native mods from PiBOH/offhorizon.

Other launchers

OffHorizon looks in the usual folders, including .minecraft, SKlauncher's minecraft, instances and profiles, and the Prism, MultiMC and Modrinth layouts. A profile whose client jar is missing is completed from Mojang's public files instead of stopping with “Missing …”.

Folders

  • The launcher's own data lives in %APPDATA%\horizon-launcher (settings, logs, the prepared game).
  • Worlds, options and packs live in the game folder shown in the launcher, one folder per instance.
  • The copy of the launcher itself lives in %APPDATA%\offhorizon.

Logs and crashes

Settings → About opens the logs folder. Crash reports sit beside it. Nothing in those files is ever uploaded: OffHorizon has no telemetry endpoint at all.

Updating

Download the newest file from Releases and replace the old launcher. Worlds, settings and the game folder stay where they are.
