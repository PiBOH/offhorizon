Terms

Terms of use

OffHorizon is free, open source and unofficial. There is no shop, no cosmetic to buy and no account to create with us.

Licence

OffHorizon is released under the Unlicense: no warranty and no liability, use it as you like. It derives from Horizon, whose own code is MIT-licensed by the Horizon contributors; that attribution stays in the project's notices.

No sale

Nothing on this site is sold. There is no shop, no cosmetic, no subscription and no payment flow; there is nothing to refund because nothing is bought.

What OffHorizon is not

It is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft. It contains no Minecraft code, assets or game files: it runs the copy of Minecraft: Java Edition you already own and can download Mojang's public version files for you.

Offline accounts

An offline account is a local name. It is meant for singleplayer and LAN, and for servers that accept it. Online servers still check a Microsoft account, and OffHorizon does not provide a way around that: it never pretends to own a game you do not own.

Google, Mojang and GitHub

Downloading game files, Horizon builds and launcher updates means connecting to those services under their own terms. OffHorizon is a client for them, not a party to them.

Changes

These terms describe OffHorizon 0.2.1-nightly and can change with the project. The history of every change is in the repository.
