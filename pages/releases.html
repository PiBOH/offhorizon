Releases

Every release, one portable file

Releases are built by GitHub Actions from a tag and published with checksums. Nothing is installed: you replace the file to update.

Get the launcher

  • The latest release (v0.1.5-nightly) — the Windows x64 launcher, the Linux x86-64 executable, the source archive and SHA256SUMS.
  • All releases — every build, newest first, with what changed.

The buttons on this site download v0.1.5-nightly, the newest build. Every release carries its own tag, so a newer one means a newer set of links; this page and Open all releases stay as the way to older builds.

Files in a release

  • OffHorizon-Launcher-Windows-x64.exe: the portable Windows launcher.
  • OffHorizon-Launcher-Linux-x86_64: the Linux executable.
  • SHA256SUMS: the checksum of every file, so you can verify a download.

Versions

The version in version.txt is the single source of truth, and a suffix such as -nightly marks a pre-release. A build whose tag starts with v is what the release job publishes.

Updating

Download the newest file and replace the one you run. Your worlds, settings and game folder are not touched. The launcher also checks for a newer launcher version itself and can install it.

Verifying a download

On Linux: sha256sum -c SHA256SUMS --ignore-missing. On Windows: Get-FileHash .\OffHorizon-Launcher-Windows-x64.exe -Algorithm SHA256 and compare. Releases are not code-signed, so Windows SmartScreen may ask the first time.
