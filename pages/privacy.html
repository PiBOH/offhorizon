Privacy

OffHorizon keeps nothing about you

There is no telemetry endpoint, no account server of ours and no analytics on this site. This page lists what actually leaves your computer, and what does not.

In short

  • No telemetry: the launcher has no endpoint to send anything to, and the “I'm playing” ping Horizon documents is not registered here.
  • No analytics, trackers, advertisements or cookies on this site.
  • No account database: an offline account is a name in a JSON file on your own disk.
  • No crash or benchmark upload; those files stay where the game writes them.

What the launcher contacts, and why

  • Mojang's public files (piston-meta, launchermeta and the library hosts): the version manifest, the client and the libraries the game needs.
  • github.com and the GitHub release CDN: Horizon game builds, launcher updates and native mods.
  • Maven Central: a library the Minecraft host refuses to serve, checked against the same hash.

Those requests carry what any HTTP request carries — your IP address reaches the host you connect to. Nothing is sent to OffHorizon.

This site

Everything this page needs for its own layout is served from this site: one stylesheet, the images beside it, the favicon and the web manifest. It runs no script, so there is nothing to execute, nothing to count and nothing stored in your browser.

One thing comes from somewhere else: the 310 contributor avatars, loaded as images from avatars.githubusercontent.com — the same pictures GitHub serves on each profile. Those requests reach GitHub, never OffHorizon, and they are the only requests this page makes to another host. Blocking them leaves the page readable: an empty square where a face would be.

What stays on your computer

  • settings.json, accounts.json and your launcher choice of folders, in the launcher's data folder.
  • Your worlds, options and packs, in the game folder.
  • Logs and crash reports, for you to read or delete.

Removing it

Turn the Shortcuts switch off to take the menu entries away, then delete the launcher's data folder and the copy in %APPDATA%\offhorizon. Nothing else is left behind, because nothing else was installed.
