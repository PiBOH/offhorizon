What it is

Same inputs, identical outputs.

OffHorizon, sometimes called Minecraft Rust Edition, rebuilds Minecraft: Java Edition 26.3 in Rust, one subsystem at a time, and holds every piece to the same inputs as the vanilla game until the outputs are identical.

Visit contributors(opens in a new tab)

  • Your own copy

    Install Java Edition with the official launcher and play 26.3 once. OffHorizon builds its resources from those files on your machine, and never downloads or shares game files.

  • Native on three platforms

    Linux, macOS on Apple Silicon or Intel, and Windows on x64 or ARM. Worlds come from a Rust port of the vanilla generators, drawn with vanilla's block models, lighting, sky and fog.

  • Open source

    OffHorizon's code is MIT. It contains no Minecraft code, assets or data; those belong to Mojang and Microsoft under the Minecraft EULA.

Where the project started.

Below is the project's first audit of each subsystem: what its harnesses compared then, and how much of it they covered. It is not a parity claim: players still find differences, and parity work on 26.3 continues, redstone first.

Audited 2026-10-13·players still find differences: the open reports(opens in a new tab)

    Passed its harnesses

    The game loop, options, camera, auto-jump, toggle sprint/sneak, local input and the frame limiter match vanilla.

  • 02Assets and resourcesPassed its harnesses

    Passed its harnesses

  • 03Network protocol and multiplayerPassed its harnesses

    Passed its harnesses

    Joins vanilla servers; the dedicated server (--dedicated) matches vanilla's files, status ping, login, configuration, play, chunks, chat, recipes, advancements and command tree, a client built from vanilla's packet code joins it, OffHorizon joins a vanilla server, and LAN discovery matches over 462 cases (offline mode only).

  • 04Chunk storage and palettesPassed its harnesses

    Passed its harnesses

    Client and saves share paletted containers, identical to vanilla over 266 scenarios.

  • 05Section meshingPassed its harnesses

Privacy

This site sets no cookies, has no analytics or trackers and loads nothing from third parties except GitHub. When you open a release, the server keeps a one-way hash of your IP address so that release counts each visitor once; the address itself is never stored. To show the latest releases, patch notes, links and contributors, your browser asks api.github.com and raw.githubusercontent.com for them, and avatars.githubusercontent.com for the contributors' pictures; GitHub's privacy statement (opens in a new tab) covers those requests. The launcher sends nothing at all: OffHorizon collects no telemetry (opens in a new tab).
