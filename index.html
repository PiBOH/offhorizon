Install

Three steps, no account.

  1. Download the OffHorizon launcher for Windows or Linux.
  2. Open it. There is no installer: on its first start OffHorizon keeps a copy of itself in %APPDATA%\offhorizon and asks whether to add its shortcuts to the Start menu and the desktop (the same switch is in Settings). If Minecraft 26.3 is missing, it downloads Mojang's public files itself.
  3. Press Play. Choose the Rust game or a Java instance. Online servers ask for a Microsoft account; singleplayer does not.

Updating? Download the newest file and replace the old launcher. Your worlds and settings stay where they are.

Docs

What to know

The full guides — install, accounts, folders, mods, privacy — are on the docs page.

Do I need to own Minecraft: Java Edition?

Yes. OffHorizon does not include Minecraft code, assets or game files. It uses the copy you already own and can download Mojang's public version files for offline play.

Does OffHorizon work with SKlauncher?

Yes. It looks in the usual launcher folders, including SKlauncher's, and reads the profiles it finds. If a profile has no vanilla client jar, OffHorizon downloads the missing public files instead of stopping.

What is sent over the network?

The launcher contacts Mojang for game files and GitHub for launcher and mod updates. OffHorizon has no telemetry endpoint. This static site loads only its own files; there is no analytics script.

Where are my worlds?

In the game folder shown in the launcher. Each instance has its own folder; deleting a launcher version never deletes a world.

Is this the official Horizon?

No. OffHorizon is an unofficial fork of Horizon, focused on offline play and no telemetry. It is not approved by or associated with Mojang, Microsoft or the Horizon project.
